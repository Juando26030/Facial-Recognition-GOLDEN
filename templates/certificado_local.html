Quitar el aviso «No seguro»

Este servidor local de Golden usa su propio certificado. Cada computador o celular que se conecta muestra «No seguro» hasta que lo instala una sola vez. Después, la conexión sale segura (candado) y no vuelve a preguntar, aunque cambie la IP del servidor.

Computador con Windows (Chrome o Edge)

  1. Descarga y abre este archivo (doble clic): Instalar certificado en Windows
  2. Si Windows dice que protegió el equipo, elige «Más información» › «Ejecutar de todas formas».
  3. En el aviso de seguridad de Windows elige «Sí».
  4. Cierra todas las ventanas del navegador y vuelve a abrir {{ server_url or 'la dirección del servidor' }}.

No necesita permisos de administrador. Firefox: abre about:preferences#privacy › Certificados › «Ver certificados» › Autoridades › Importar, y elige el archivo golden-local-ca.cer.

Celular o tableta Android

  1. Descarga el certificado: Descargar certificado
  2. Abre Ajustes › Seguridad (o «Seguridad y privacidad») › Más ajustes › Cifrado y credenciales › Instalar un certificado › Certificado de CA.
  3. Acepta el aviso y elige el archivo golden-local-ca.cer de Descargas.
  4. Cierra Chrome por completo y vuelve a abrir la dirección del servidor.

Los nombres del menú cambian un poco según la marca: busca «certificado» en el buscador de Ajustes.

iPhone o iPad

  1. Abre esta página en Safari y toca: Descargar certificado › «Permitir».
  2. Ajustes › «Perfil descargado» › Instalar (pide el código del equipo).
  3. Ajustes › General › Información › Ajustes de confianza de certificados › activa «Golden Local CA».

Mac

  1. Descarga golden-local-ca.cer y ábrelo (se abre «Acceso a Llaveros»).
  2. Busca «Golden Local CA», ábrelo › Confiar › «Al utilizar este certificado»: Confiar siempre.
