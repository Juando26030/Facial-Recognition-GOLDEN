Cómo publicar el instalador

Lo hace el equipo técnico una vez por versión. Si el botón de descarga no aparece, pídelo a soporte.

Avanzado (solo técnicos): pasos y comandos para publicar el instalador

El botón de descarga aparece cuando el archivo del instalador está guardado en el almacenamiento de Orum. Hay que construirlo una vez y subirlo. Se repite cada vez que cambie la versión de producción.

Qué se necesita
  • Acceso al repositorio de GitHub (para el camino A) o un computador con Windows 10/11 con internet (camino B).
  • La herramienta de Google Cloud (gcloud, que trae gsutil) con tu cuenta de Golden, o la consola web de Google Cloud.
  • El nombre del almacenamiento de la app (en deploy/gcp/config.sh: APP_BUCKET y APP_PREFIX). Abajo lo llamamos BUCKET y PREFIJO.
Paso 1 · Construir el instalador

Camino A (sin Windows, con GitHub): en GitHub entra a Actions, elige «Instalador de Windows (servidor local)», pulsa «Run workflow», escribe la versión (por ejemplo 2026.11.10) y espera unos 20 a 30 minutos. Al terminar, descarga el archivo comprimido golden-local-windows y ábrelo: dentro está GoldenLocal-Setup-2026.11.10.exe. También se puede con comandos:

gh workflow run instalador-windows.yml -f version=2026.11.10
gh run watch
gh run download -n golden-local-windows -D instalador

Camino B (en un Windows): instala Git, Python 3.13 e Inno Setup 6; abre PowerShell y escribe:

git clone https://github.com/Juando26030/Facial-Recognition-GOLDEN.git
cd Facial-Recognition-GOLDEN
git checkout f5/integracion
Set-ExecutionPolicy -Scope Process Bypass
.\deploy\windows\build_installer.ps1 -Version 2026.11.10

El archivo queda en build\windows\out\GoldenLocal-Setup-2026.11.10.exe.

Paso 2 · Subirlo al almacenamiento

El nombre del archivo debe ser exactamente GoldenLocal-Setup-<versión>.exe. Con gcloud instalado:

gcloud auth login
gsutil cp GoldenLocal-Setup-2026.11.10.exe gs://BUCKET/PREFIJO/system/local-installer/

Si el entorno no usa prefijo, la ruta es gs://BUCKET/system/local-installer/. Sin comandos: en la consola web de Google Cloud, Cloud Storage, abre el almacenamiento, entra a la carpeta system/local-installer (créala si no existe) y arrastra el archivo.

Paso 3 · Comprobar
  1. gsutil ls gs://BUCKET/PREFIJO/system/local-installer/ debe mostrar el archivo.
  2. Recarga esta página y abre «Servidor local»: la tarjeta de arriba debe decir Disponible con la versión, en vez de «Aún no disponible».
  3. Pulsa «Descargar instalador para Windows» y confirma que baja el archivo.

Si hay varias versiones guardadas se ofrece la más alta. Para retirar una, bórrala de esa carpeta.

Cómo funciona, en pocas palabras

¿Qué es?
Una copia de Orum que vive en un computador del evento. El personal se conecta a ese computador con el wifi del lugar y trabaja como siempre, sin necesitar internet.
¿Qué necesito?
Un computador con Windows 10 u 11, 8 GB de memoria, un router o wifi propio para que los demás equipos se conecten, y internet solo al principio (para instalar y bajar el evento).
¿Cómo se usa?
  1. Con internet, descarga el instalador de aquí y ábrelo con doble clic. Acepta los permisos y espera unos minutos.
  2. Entra con tu mismo usuario y contraseña de siempre.
  3. Elige tu evento y pulsa «Descargar a local». El evento queda en ese computador.
  4. El día del evento, conecta los demás equipos al mismo wifi y trabaja normalmente.
¿Y el evento en internet?
Mientras un evento está en el servidor local, en internet solo se puede ver, no cambiar. Así nunca se mezclan dos versiones. Un solo lugar manda a la vez.
¿Qué pasa si no hay internet?
Nada: todo sigue funcionando. Cuando vuelva el internet, el servidor sube solo lo que se hizo (cada 30 minutos). Al terminar, pulsa «Pasar a internet» para que el evento vuelva a poder editarse en la nube.

Una explicación más larga, sin términos técnicos, está en el documento «Explicación del servidor local».

Alertas del sistema

Si alguien borra muchos registros de golpe (eventos, formularios, inscripciones, personas, archivos), el sistema envía un correo al instante. El correo dice quién, qué, cuántos y cuándo, y nunca incluye datos de los asistentes. La limpieza automática de privacidad no cuenta como alerta.

¿Desde cuántos registros se avisa?

{% call ayuda('ay_alsettings', 'Umbral de la alerta') %}Se avisa cuando UNA acción borra al menos «registros en una acción», o cuando la misma cuenta acumula al menos «registros acumulados» dentro de los minutos indicados.
